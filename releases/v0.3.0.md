# Model2EmuEx Libretro 0.3.0

This release adds the native Model 2C TGPx4 reconstruction to all five platform
packages. The catalogue now contains 70 MAME-aligned sets, including 13 recovered
Model 2C records.

- Recovered CPU, decoder, driver, FIFO and machine bindings preserve the original
  ElSemi behavior. Model 2C uses complete 16 MiB Libretro Save State buffers,
  including fresh-session restoration.
- Integrates the native Top Skater geometry path, Ski Super G motion handshake,
  ROM transformations and Dynamite Cop protection handlers.
- Retains SM2-style frontend profiles and NVRAM controls. Sonic's two energy
  selectors preserve the original conditional Service Menu writes and correctly
  reapply configured overrides after native menu edits and content reload.
- Distribution builds explicitly enable both `SHARC=1` and `TGPX4=1`, with
  machine and geometry regression gates. Core names and raw Save RAM stay unchanged.

Validation includes original-binary differential checks, all 22 floating-point
handlers executed natively on AMD hardware, representative macOS/Batocera/Windows
VM runs and Save State restoration. Top Skater's same-input pre-backend geometry
comparison matches all 2,753 sampled interior vertex occurrences within 1/16 pixel
without position correction. This is spatial correspondence, not pixel, topology
or attribute identity. See `MODEL2C_ANALYSIS.md` and `VALIDATION.md` for scope.

Packages target Linux x86-64/ARM64, macOS Apple Silicon/Intel and Windows x86-64.
Desktop OpenGL is required. Matching source and `SHA256SUMS` accompany the ZIPs.
Coverage is not exhaustive gameplay, audio or physical-peripheral certification.
Unrecovered native-memory accesses stop explicitly rather than using fabricated
fallback data. External linked sessions remain ineligible for Save States.
