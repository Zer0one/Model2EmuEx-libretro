# Model2EmuEx Libretro 0.1.0

First independent rolling release, preserving Model2EmuEx history and native
emulation with SM2-style frontend integration.

## Downloads

- **Linux x86_64 / ARM64:** matching `linux-x86_64` / `linux-arm64` ZIPs.
- **Windows x86_64:** matching `windows-x86_64` ZIP.
- **macOS Intel:** matching `macos-x86_64` ZIP.
- **macOS Apple Silicon:** `model2emuex-libretro-macos-arm64-0.1.0.zip`.
  macOS 13.0 build minimum; arm64 frontend and desktop OpenGL (`gl`) required.
- **Matching source:** `model2emuex-libretro-source-0.1.0.tar.gz`.
- **Integrity:** `SHA256SUMS`; the platform ZIP also has internal checksums.

Copy the core into the frontend cores directory and the matching `.info` into
its information directory. No external games.xml is required. ROMs are not
included; use the canonical MAME set/parent names documented in LIBRETRO.md.

## Included

- Native OpenGL resolution/filtering, colour and shadows/fences controls.
- Separate aspect/widescreen options and 60 Hz/native 58 Hz timing.
- Adapted SM2 input profiles, NVRAM settings/templates, source gains, crosshairs,
  rumble callbacks and timing overlay.
- Standalone-compatible 65,664-byte raw Save RAM and native Save States.
- External linked-cabinet Netpacket transport, role options and local loopback.
- Native SCSP streaming, EEPROM and Sega Rally backdrop corrections.

## Coverage And Limits

macOS arm64 has representative real RetroArch rendering/persistence/state and
linked-cabinet evidence, plus 33 native Input Test cases across Sega Rally/VF2.
CI verifies builds and packaging without ROMs; it does not certify gameplay.
Model 2B/2C execution remains unavailable. Physical-device qualification and
actual gameplay on platforms beyond macOS arm64 remain unverified. Live Normal-profile editing and the supplementary
exact-frame custom-crosshair state probe remain uncompleted.
