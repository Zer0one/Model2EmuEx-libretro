# Model2EmuEx Libretro 0.4.0

This release integrates the reconstructed ElSemi audio subsystem, original Lua
support, selected native renderer options and input-route corrections.

- Audio Subsystem (Restart Required) selects Model2Emu (ElSemi), the default,
  or Model2EmuEx. The choice binds the complete primary sound board rather than
  independent CPU and DSP combinations. The reconstruction includes A68K,
  SCSP voices/mixer/DSP, the Model 1-style MultiPCM/FM board, optional DSB,
  original timing, board exchanges and complete offline snapshots.
- Embeds Lua 5.1.4 with per-game scripts, script-declared Core Options, reload,
  fonts and overlays. Active scripts run machine/Frame/render/PostDraw in
  sequence. Lua interpreter state remains session-owned across Load State.
- Adds 2x FSAA, automatic mipmaps, texture replacement, Fake Gouraud Shading
  and 2D tilemap filtering. Converted original mode shaders use GLSL.
  Unsupported FSAA notifies without changing the stored selection.
- Completes the source input-route comparison for all 70 sets. Corrects Virtua
  Cop counter publication, Water Ski pitch polarity, Super GT 24h live I/O-Type
  pedal conversion and Model 2B/2C long I/O reads. Gun aiming follows the
  effective expansion of the last presented scene, including Lua changes.
- Preserves standalone-compatible raw Save RAM, SM2-style frontend controls,
  canonical core filenames and the existing Model 2/2A/2B/2C catalogue.

User assets belong under the RetroArch system directory in model2emuex:
scripts/<romset>.lua, scripts/assets/ for script resources and TTF fonts,
textures/<romset>.pat, textures/<romset>/ for replacement images, and
textures/mode_<N>.frag for converted shaders. See LIBRETRO.md for exact rules.

Validation includes original-binary differential comparisons, matched audio
traces, accepted listening samples, both macOS architecture input/ABI checks,
fresh-session Save State continuation and bounded real RetroArch execution.
All eight defined ElSemi audio adoption groups are closed. Remaining original
memory/reachability research is optional and deferred; this is not a claim of
complete executable reconstruction or exhaustive gameplay/peripheral coverage.
Explicit safety diagnostics remain for unrecovered or out-of-bounds accesses.
External linked sessions remain non-serializable. State compatibility between
audio profiles or older development builds is not promised.

Packages target Linux x86-64/ARM64, macOS Apple Silicon/Intel and Windows x86-64.
Desktop OpenGL is required. The five-platform build/ABI/package and machine
checks gate publication. Matching source and SHA256SUMS accompany the ZIPs.
