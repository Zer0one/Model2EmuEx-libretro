# Model2EmuEx Libretro 0.2.0

This release adds the native Model 2B SHARC reconstruction and aligns all 35
Model 2B ROM sets with the pinned MAME catalogue.

- Model 2B Save States use the existing core snapshot contract with a 16 MiB
  buffer. Active external cabinet sessions remain ineligible for Save States.
- Power Sled supports the Slave, Relay and reconstructed Main programs. Main
  and Relay can run alone with the guarded SM2 program patches. A mixed
  Main–Relay–Slave session was verified in RetroArch on macOS.
- The Power Sled upload and communication changes are confined to those
  three sets. Other titles retain the reconstructed ElSemi upload path.
- All packages and local build tools use the canonical `model2emuex_libretro`
  basename.

Packages are available for Linux x86-64 and ARM64, Windows x86-64, and macOS
Apple Silicon and Intel. The matching source and `SHA256SUMS` accompany the
platform ZIPs. Desktop OpenGL is required. Model 2C execution remains
unavailable. The catalogue is not an exhaustive gameplay or peripheral
certification. See `SHARC_RECONSTRUCTION.md` for the exact validation scope.
