# Model2EmuEx Libretro 0.5.0

This release completes the 88-set MAME-aligned catalog and integrates the native
machine support needed by its 20 additional sets.

- Recovers six initialized Model 2A definitions from ElSemi 1.1a: doaa,
  pltkidsa, dyndeka2, dynamcop, zerogunaj and zeroguna, including original
  ROM operations, inputs and protection installers.
- Adds eleven existing-family revisions: doaab, doaae, hotd, hotdp, manxttdx,
  motoraiddx, srallycc, srallycdx, srallycdxa, stcco and topskatruo.
- Adds Air Walkers, Hanguk Pro Yagu 98 and Royal Ascot II using the native
  board paths. Air Walkers includes four-player input multiplexing, direction
  and output readback, and correctly sized EEPROM register writes.
- Preserves native protection response/state behavior and bounded observable
  process aliases. Unknown native addresses stop content with a diagnostic.
- Follows canonical MAME set identifiers and parents while retaining the core's
  display titles. daytonat/daytonata remain excluded by user decision; the
  pristine standalone catalog remains separate.
- Applies the current SM2 Zero Gunner 2A operator-data donor independently of
  its Model 2B MAME parent. Existing NVRAM options/defaults and native raw SRAM
  compatibility are preserved; no excluded operator settings are added.
- Extends offline snapshots for protected boards and Air Walkers' I/O matrix.
  Incompatible earlier payloads are rejected explicitly; Save RAM is unchanged.
- Adds native-protection, Air Walkers I/O, all-profile and NVRAM checks to every
  supported platform's package gate. Retains reusable catalog and NVRAM audit tools.

Local qualification includes 20 bounded startup witnesses, nine repeated
Save State continuations and four fresh-process state continuations. Both
macOS architecture fixture suites pass. The universal core renders Air Walkers
and Dead or Alive Model 2A in actual RetroArch; VF2 and doab state regressions pass.

Startup qualification is not exhaustive gameplay acceptance. hotdp remains on
its warning screen after 2,700 frames, also reproduced in current SM2; playable
prototype status is not claimed. Royal Ascot II reaches its native SegaNet wait
screen and its standalone title through the game's own Shot 1 path. Physical
controllers, wider gameplay and other-platform runtime retain their documented
limits. External linked sessions remain non-serializable.

Packages target Linux x86-64/ARM64, macOS Apple Silicon/Intel and Windows x86-64.
All five build/ABI/package and machine/integration gates must pass before
publication. Matching source and SHA256SUMS accompany the five core ZIPs.
